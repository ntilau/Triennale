Samtec OrCAD Capture Design Kit Installation Instructions

1.  Unzip the folder entitled Capture_XXX_XXX downloaded from Samtec.com

2.  In the 'PLace Part' menu select 'Add Library' and choose the .OLB file downloaded from Samtec.com

3.  In the simulation settings, add all of the .LIB files in the 'Library' section of the 'Configuration Files' to ensure simulations run correctly.

4. Contact Sig@Samtec.com with any questions/problems encountered
